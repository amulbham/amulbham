# Amul Bham

I'm a systems researcher interested in how AI systems reason, remember, and work with people. Much of my work explores a related question: as these systems become more capable, how do we make their behavior more reliable, their decisions easier to examine, and their work easier to carry forward?

I approach these questions through a mix of research, writing, and building. My background is in enterprise digital systems, where I spent more than a decade working on problems involving search, technology, and large-scale operations. More recently, I've been applying that experience to AI.

## Current projects

### [amulbham.com](https://amulbham.com)

My independent research and writing site, built with Astro.

The website is also a project in its own right. I use AI tools throughout development, from planning and implementation to reviewing changes and testing releases. Over time, I've built a workflow that keeps the original decisions, the implementation, and the evidence of what actually shipped connected.

[Website](https://amulbham.com) · [Source code](https://github.com/amulbham/cybernetics-mbp)

### [Mission Brief Protocol (MBP)](https://github.com/amulbham/mission-brief-protocol)

An ongoing research project exploring whether reasoning can be made more reliable by giving it explicit structure, constraints, and verification requirements.

The project began as an experiment in how language models handle complex tasks and has since developed into a broader investigation of reasoning, memory, and continuity. The repository contains the evolving architecture, its research history, and a versioned kernel with build and validation tests.

[Repository](https://github.com/amulbham/mission-brief-protocol)

### Shared Project Memory (SPM)

A smaller project that grew out of working across different AI models and conversations.

The basic idea is straightforward: important project decisions shouldn't disappear when a conversation ends. I've been experimenting with Git-backed project memory that allows another session or model to recover the work without reconstructing everything from a chat history.

Early recovery tests have been promising, though the broader approach is still being developed.
